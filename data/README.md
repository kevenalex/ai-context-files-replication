# data

Data used in the paper, organized by stage. Each folder has its own `README.md`.

- `collection/`: SEART repositories, ranking, top 10,000, detection of the context files, and downloaded content.
- `rq01/`: manual annotation of the sample and classification of the 1,828 files by an LLM.
- `rq02/`: frame and sample of repositories with two or more files, manual annotation of the relationships, and evidence.

Two large files are not versioned: the full SEART export, which comes from the supplementary
material of Mohsenimofidi et al., and the full ranking, which is regenerated by the script (see
`collection/README.md`). All other files are here.

**Language of the data files.** The annotation and classification files keep the column names and
labels with which they were recorded, in Portuguese. The README of each folder translates them.
