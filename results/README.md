# results

Tables (CSV) and figures (SVG and PDF) produced by the notebooks, with the same division by stage:
`collection/`, `rq01/`, and `rq02/`. Nothing here is edited by hand; to regenerate, run the notebooks
(see the root `README.md`). The mapping between each file and the paper is in the root `README.md`.

The `sample_reproduction/` and `ranking_reproduction/` folders hold the outputs of the reproductions
of the collection and classification steps (see the root `README.md`).
