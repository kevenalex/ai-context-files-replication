## Ranking

The ranking uses the script of the replication package of Mohsenimofidi et al.
(`scripts/ranking/ranking.py`, unmodified). Two settings in `scripts/ranking/run_ranking.py` are
needed to obtain the same ranking as the study:

- **Reference date.** The project age is computed from the moment the script runs. The study's
  ranking was generated on 2026-04-01, and the script fixes that date.
- **Rounding.** `rank_score` is rounded to two decimals, which creates ties.

With these settings, all positions of the ranking match those of the study. The cut-off at 10,000
falls inside a group of 10 tied repositories (position 10,002.5), and two of them
(`firewalla/firewalla` and `testcontainers/testcontainers-python`) enter or leave depending on the
tie-breaking order. That is why the top 10,000 used in the study is distributed ready-made.

## Detection and download

The detection queries the GitHub API at the default path of each format: the repository root, or
`.github/copilot-instructions.md` for Copilot. The download uses the same API. Of the 1,858 detected
files, 1,828 were downloaded; the 30 failures are in the manifest with `status = failed`.
